# Dictionary sources

`formulary.json` and `ems_terms.json` are generated by `core/tools/build_dictionary.py`
(re-run with `--offline` to rebuild from the committed cache `core/tools/.dict_cache.json`).

| Source | What we took | How |
|---|---|---|
| Massachusetts Statewide Treatment Protocols v2024.1 (mass.gov/oems) | Drug list, typical adult doses, routes, high-alert flags | Curated by hand into `SEED` in the builder |
| NY REMAC Prehospital Treatment Protocols; Wake County EMS System Clinical Protocols; NC College of EMS Physicians protocols | Cross-check of drug list, slang (DuoNeb, push-dose epi, D10) | Curated |
| RxNorm REST API — https://rxnav.nlm.nih.gov/REST/ (NLM) | RXCUI, single-ingredient brand names (TTY=BN, filtered to one IN) | Fetched by the builder, cached |
| openFDA drug label API — https://api.fda.gov/drug/label.json | Label routes (`openfda.route`) per generic → `label_routes_openfda` | Fetched by the builder, cached |
| NEMSIS v3.5.1 XSDs — https://nemsis.org/media/nemsis_v3/release-3.5.1/XSDs/NEMSIS_XSDs/ | Route codes (eMedications.04 / CurrentMedicationAdministrationRoute 99270xx), dose unit codes (eMedications.06 37060xx), eTimes.11 / eTimes.12 definitions | Parsed from `commonTypes_v3.xsd`, `eMedications_v3.xsd` |
| NREMT National EMS Education Standards / EMT course glossaries (e.g. Brady *Emergency Care*, AAOS *Emergency Care and Transportation of the Sick and Injured*), common EMS abbreviation lists | Abbreviations, assessment shorthand (A&O×4, PERRL, OPQRST, SAMPLE, DCAP-BTLS) | Curated into `TERMS` |
| Two EMT interviews (team notes) | Status shorthand ("compensating", "decompensating"), dispatch-vs-found phrasing, wall-time language | Curated |

ASR variants: hand-written misrecognitions plus spelling variants that keep the same
phonetic key (`core/tools/phonetic.py`, a Metaphone port; the Swift runtime uses the
identical rules in `EarshotCore/Text/Phonetic.swift`).

Doses are reference values for plausibility only. Earshot never fills a dose it did not hear.
NEMSIS unit code `3706029` ("Other") is used where NEMSIS has no exact unit (ml/kg, g/kg, meq/kg, kit).
